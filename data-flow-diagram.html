🗄️ PostgreSQL Database Schema (Prisma)
Employee
id - Primary Key
username - Unique login
password - Hashed
role - admin/staff
status - active/inactive
timestamps - Login/logout
Product
id - Primary Key
name, sku - Identification
price - Selling price
cabinet - Location
category - Foreign Key
stockBatches - One-to-Many
StockBatch
id - Primary Key
productId - Foreign Key
quantity - Stock count
status - on-shelf/sold/reserved
cabinet - Batch location
batchDate, expiryDate - Tracking
Sale
id - UUID
items - One-to-Many
amount - Total price
staffName - Who sold
paymentMethod - Payment type
archived - Remittance status
SaleItem
id - Primary Key
saleId - Foreign Key
productName - Item name
quantity - Units sold
price - Unit price
category - Product category
Category
id - Primary Key
name - Unique category
products - One-to-Many
Key Data Flow Processes
1️⃣ Sale Creation Flow
• User selects products in POS
• Frontend adds items to cart
• POST /api/sales creates Sale + SaleItems
• Stock batches updated
• Activity logged
• Offline sync if needed
2️⃣ Inventory Update Flow
• Admin adds new products
• POST /api/products creates Product
• POST /api/stock-batches creates batch
• Cabinet inventory updated
• StockBatch status tracked
• ProductsContext notified
3️⃣ Remittance Flow
• Staff views unarchived sales
• System calculates remittance
• POST /api/sales/archive marks paid
• Sale.archived = true
• RemittanceContext updated
• Activity logged for compliance
4️⃣ Activity Logging
• Login event → Activity record
• Logout event → Activity record
• Sales transaction → Log entry
• POST /api/activities/[id]
• Timestamp synced (±8 hours)
• Staff analytics updated
5️⃣ Offline Sync Flow
• Detect offline status
• Queue API requests
• Store locally (offlineStorage)
• Display optimistic UI
• Reconnect → Sync service
• Batch API calls, retry logic
6️⃣ Analytics Flow
• GET /api/analytics retrieves data
• Aggregates Sales + SaleItems
• Calculates trends & metrics
• Filters by date/cabinet/staff
• Admin/Staff dashboards display
• Real-time updates via context
